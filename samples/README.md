# Samples

Sample games, written in C++20 and identical on every platform. Samples use the engine's public API
and never include platform or backend headers.

| Sample | Shows |
|---|---|
| [arcade_demo](arcade_demo) | A small game using everything: physics, music and sounds, a HUD and menu, ImGui debug tools, and on PC a profile of each run, a memory budget and a crash you can switch on to try crash reports. Its checks run it with Jolt, miniaudio and RmlUi, and again with impulse, PortAudio and markup |
| [cube](cube) | A spinning cube drawn with Vulkan or DirectX on PC and Vulkan on Android, with Slang shaders |
| [render_demo](render_demo) | A lit, textured 3D scene drawn by the engine's renderer from a scene file |
| [physics_demo](physics_demo) | 3D and 2D physics from scene files, with shooting, sensors, joints and debug shapes, checked with Jolt and Box2D and with impulse and Chipmunk |
| [scene_demo](scene_demo) | Scenes in TOML files, built from components, using shared assets and events |
| [hello_game](hello_game) | A complete game on PC and Android: window, lifecycle, files and input actions. A check runs it with the profiler and reads the trace |
| [module_demo](module_demo) | Choosing a backend from `dream.toml`, with no backend named in the code |

The models and sounds in [assets](assets) are shared by the samples, and generated by
[tools/make_sample_models.py](../tools/make_sample_models.py) and
[tools/make_sample_sounds.py](../tools/make_sample_sounds.py). The fonts are Lato, under the
[SIL Open Font License](assets/fonts/LICENSE-Lato.txt).
