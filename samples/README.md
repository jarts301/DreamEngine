# Samples

Sample games, written in C++20. Samples use the engine's public API and never include platform or
backend headers. On this branch each one is played in a web browser and drawn on the CPU
(ADR 0039); start them from the hub (`build/tools/hub/dream_hub`) or run them and open the address
they print.

| Sample | Shows |
|---|---|
| [toppler](toppler) | A 10-level knockdown puzzle game: physics, a menu and HUD, saved progress. Its check plays every level |
| [arcade_demo](arcade_demo) | A small game using everything: physics, sounds, a HUD and menu, ImGui debug tools (F1), a profile of each run, a memory budget and a crash you can switch on to try crash reports |
| [render_demo](render_demo) | A lit, textured 3D scene from a scene file: materials, shadows, point and spot lights, a skinned tentacle and a campfire of particles |
| [physics_demo](physics_demo) | 3D and 2D physics from scene files, with shooting, sensors, joints and debug shapes, checked with impulse and Box2D |
| [hello_game](hello_game) | A complete small game: window, lifecycle, files and input actions. A check runs it with the profiler and reads the trace |
| [module_demo](module_demo) | Choosing a backend from `dream.toml`, with no backend named in the code |

The models and sounds in [assets](assets) are shared by the samples. They were generated by the
Python scripts in [tools](../tools) and are kept in the repository, so building needs no Python.
The fonts are Lato, under the [SIL Open Font License](assets/fonts/LICENSE-Lato.txt).
